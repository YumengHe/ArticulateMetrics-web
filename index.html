Articulate Metrics

Anonymous

✨ Abstract ✨

Methods that reconstruct simulation-ready articulated objects are evaluated by an ad-hoc template of per-joint scores: an axis-direction error, a pivot error, a categorical joint-type error, and, in the most complete protocols, a motion-limit error, reported separately or thresholded into a success rate. We show this template grades the representation rather than the motion it encodes. The pivot term divides by the cross product of the two axes and so diverges precisely when predictions become accurate; the type error is discontinuous at the fixed/revolute/prismatic boundaries that are physically continuous; and where the limits are scored, they are folded back onto the axis in a way that reintroduces the axis-sign ambiguity, so the same joint written with a flipped axis and renamed limits scores maximally against itself and unbounded joints cannot be scored at all. We propose a single metric on one-DOF joints that removes each of these failures by construction: the quotient distance between the unordered pair of Lie-algebra endpoint twists of the two joints. It is a true metric, unifies fixed, revolute, prismatic, and helical joints, admits unbounded (continuous) joints as limit points of a radial compactification, and, under the kinetic-energy inner product of the moving link, equals the RMS physical displacement of that link's material, turning the score into a motion discrepancy in meters. We lift the metric to full kinematic trees with geometry, prove its metric axioms and its equivalence to swept-motion discrepancy, and outline re-evaluation of published methods on PartNet-Mobility under it.

📖 Documentation 📖

Usage documentation for articulatearena, the reference implementation of the quotient metric E on one-degree-of-freedom articulated joints and its object-level lifts.

1Overview

articulatearena implements a principled distance between articulated-kinematics predictions and ground truth. A one-DOF joint J with unit screw twist ξ̂ ∈ se(3) and limits [a, b] is represented by its unordered endpoint pair {a·ξ̂, b·ξ̂}; the joint metric is the quotient distance

E(J₁, J₂) = min over the ℤ₂ swap of ( ‖u₁ − u₂‖ + ‖v₁ − v₂‖ ),

where ‖·‖ is an injected se(3) norm. The package provides the metric itself, a smooth training surrogate, the radial compactification that extends the metric continuously to unbounded (continuous) joints, and two object-level lifts: an optimal-assignment skeleton distance and a motion-aware tree edit distance with a certified assignment relaxation.

All functions are pure: norms, weights, and tolerances are passed in by the caller and never hardcoded. The library depends only on numpy, scipy, and pyyaml.

2Installation

The package lives in src/articulatearena/ of the ArticulateMetrics repository and follows the standard src layout. From the repository root:

$ conda create -n articulatemetrics python=3.10 -y
$ conda activate articulatemetrics
$ pip install -e .

An editable install registers the import name articulatearena; the repository scripts also run without installation, as they place src/ on sys.path themselves. Python ≥ 3.10 is required.

3Quickstart

Build endpoint pairs for two joints, choose an se(3) norm, and evaluate joint_metric. The distance is 0 exactly when the two joints induce the same motion:

import numpy as np
from articulatearena.new_equation.representation import make_endpoint_pair
from articulatearena.new_equation.inner_product import make_split_norm
from articulatearena.new_equation.E import joint_metric

xi = np.array([0., 0., 1., 0., 0., 0.])   # unit screw axis (omega; nu)
gt   = make_endpoint_pair(xi, 0.0, 1.0)    # joint limits [a, b]
pred = make_endpoint_pair(xi, 0.0, 1.0)

norm = make_split_norm(alpha=1.0)          # the norm is injected, never hardcoded
E = joint_metric(gt.u.data, gt.v.data, pred.u.data, pred.v.data, norm)
print(E)   # 0.0 when prediction == ground truth

To score real URDF joints, load them through the reader layer instead of constructing twists by hand:

from articulatearena.read.urdf_loader import load_joint
from articulatearena.new_equation.representation import joint_to_endpoint_pair

joint = load_joint("sample_data/45168/mobility.urdf", "joint_0")
pair  = joint_to_endpoint_pair(joint)      # unordered {a*xi, b*xi}

4Core concepts

4.1 Endpoint pairs and the metric E

A joint is identified with the unordered pair of its endpoint twists u = a·ξ̂, v = b·ξ̂. Because the pair is unordered, joint_metric takes the minimum over the two pairings — this is the quotient by the ℤ₂ swap and what makes E well defined on joints rather than on labeled endpoint tuples. The hard min is non-differentiable on its tie locus, so training_loss provides a smooth, swap-invariant surrogate for E² suitable as a learning objective.

4.2 Injected se(3) norms

Every metric function takes an InnerProduct — a callable mapping a shape-(6,) twist to its squared norm. Three constructors are provided:

ConstructorNorm
make_split_norm(alpha) ‖ω‖² + α²‖ν‖², the dimensionless benchmark default (α is a characteristic inverse length; set it to match your units).
make_kinetic_energy_norm(inertia) ξᵀ M ξ from a child link's LinkInertia (mass, center of mass, rotational inertia); values carry physical units.
make_riemannian_norm(metric) ξᵀ G ξ for an arbitrary user-supplied symmetric positive-definite 6×6 matrix G.

4.3 Continuous joints and the compactification E∘φ

A continuous joint has unbounded limits, so its endpoint twists escape to infinity. radial_compactify applies the radial map φ(ξ) = tanh(‖ξ‖/κ)·ξ/‖ξ‖, which carries all twists into the open unit ball and continuous joints to points on its boundary; compactified_joint_metric evaluates E∘φ there. This composition is continuous as a bounded joint's range grows toward the continuous limit, so bounded and continuous joints are compared on one compact space. The benchmark uses κ = π. interval_term supplies the extended-real comparison of the limit intervals themselves.

4.4 The tree metric

At object level a kinematic tree has links for nodes and one-DOF joints for edges. The tree metric Etree is an edit distance: substituting the joint on an edge costs E(J, J′), and contracting or expanding an edge costs E(J, J₀) — the motion the joint carries — where J₀ is the fixed joint. Exactly-fixed edges are contracted first (contract_small_edges); they are representation noise, not structure.

Two computations are provided:

FunctionSemantics
assignment_tree_distance The assignment relaxation: a Hungarian matching over the joint multisets with E(J, J₀) as the unmatched cost. Polynomial for any input; a certified lower bound of the exact distance; needs no tree topology from the prediction.
exact_tree_distance The exact edit distance: the minimum over matchings that extend to an isomorphism of the contracted trees. Returns (distance, certified); when the relaxation's own optimal matching is realizable (checked in linear time by matching_realizable), exactness is certified without any search.

Unordered tree edit distance is NP-hard for general trees, which is why the benchmark protocol is stated with the relaxation. At benchmark scale (2–8 movable joints) the exact distance is cheap: the certificate settles ≈ 91 % of corrupted predictions, the two quantities agree on ≈ 92 % of them (rank agreement τ = 0.994), and they agree exactly on every structured sweep.

A simpler object-level alternative, skeleton_distance, adds a constant topology penalty λ per unmatched joint on top of the assigned E cost; it is retained for comparison with prior hard-penalty protocols.

6Command-line usage

The repository entry point evaluates a prediction/ground-truth case end to end — load the config, run the pure metric functions, and write a report:

$ python scripts/run.py --config configs/default.yaml
# → Report written to out/metrics_report.json

configs/default.yaml groups the knobs that the paper treats as caller-supplied:

GroupKeys
inner_productform (split / kinetic / riemannian), split_norm_alpha, riemannian_metric.
compactificationkappa (benchmark: π), phi_at_zero.
skeletonlambda_topology, topology_penalty, tree_edit_distance.
aggregation, geometryAggregation form, smoothing ε, geometric weighting.
prediction, ground_truthURDF path + joint name of each side of the case.

Auxiliary scripts: scripts/generate_error_cases.py synthesizes controlled error cases from a URDF; scripts/run_previous_metrics.py scores the same cases with the baseline component metrics; examples/run_real_cases.py evaluates real PartNet-Mobility objects.
